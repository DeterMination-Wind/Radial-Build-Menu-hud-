# 测试指南

RBM **没有自动化测试**：`build.gradle` 未注册任何测试任务，也没有测试源码（`gradlew test` 只会空跑）。质量保障以游戏内手测为主，按下述清单逐项过。

## 手测约定

- 用 `.\gradlew.bat clean deploy` 出合并包，装入 `mods/` 后重启游戏验证（见[开发指南](development.md)）。
- 改了哪个子系统就至少覆盖对应条目；发版前整套清单都要过一遍。
- 涉及设置键、导入导出的改动，额外验证旧配置升级不丢数据。

## 手测清单

1. **基础圆盘**
   - `设置 → 控制` 能找到 "Radial Build Menu" 键位；绑定后按住出盘、移动选择、松开切换到目标建筑。
   - 内圈 8 槽默认配置（conveyor/router/...）；只配外圈时外圈自动出现；未配外圈时不显示。
   - "显示空槽位"开启后 16 个角度固定，关闭后只画已配置槽位。
2. **选择逻辑**
   - 悬停图标命中；开启"方向选择"后未悬停也能按方向选中；中心死区内不选。
   - 鼠标在内圈半径内时永不误选外圈槽位。
   - "悬停判定间隔 / 悬停补偿 / 方向死区"滑条变化符合预期。
3. **轮盘方案（Wheel Profiles）**
   - 新建 / 复制 / 删除 / 重命名；上限 32 套时"添加"禁用。
   - 给方案绑独立热键后按该键直接以方案内容开盘；数字键 1-0 绑定时出现"与原生方块快捷键冲突"提示；两方案同键时出现重复提示。
   - 删除最后一个方案被阻止；删除激活方案后激活状态复位。
4. **规则切换**
   - 时长槽位：设定 X 分钟后开局，到点切到时长配置。
   - 星球覆盖（专业模式）：Erekir / Serpulo / Sun 分别生效，可单独开关。
   - 自动槽位组（专业模式）：按列表顺序取第一个条件为真的组；表达式支持 `planet`、`@thisteam`、`blue.copper`、`blue.poly`、`xxxcount`。
   - 非法表达式输入不崩溃、按 false 处理；改正后恢复。
5. **槽位组 A/B**
   - "槽位组设置"能分别配置 A/B 两组并导入导出；热键与当前组状态在设置行可见。
   - 与"常驻 HUD"同时开启时，常驻圆盘按上下文/规则槽位显示（v5.7.1 修复的行为，重点回归）。
   - 注意：当前源码快照中 HUD 填充路径未消费 A/B 槽位内容（见[架构总览](architecture.md)槽位来源第 4 条），此区域有改动时先确认实际接线再测。
6. **He 快捷栏同步**
   - 安装 Helium 并开启其"更好的放置"后开启同步：圆盘槽位 1-8 实时镜像 He 快捷栏当前页，翻页跟随；未装 He 时静默回退自身规则。
7. **常驻 HUD**
   - 开启后未按键时低透明度跟随鼠标；按住热键冻结在原地，松开恢复；透明度独立可调；"HUD 始终居中"叠加生效。
8. **导入/导出**
   - 导出 JSON 可复制；粘贴导入后外观、全部槽位前缀、轮盘方案、自动槽位组及激活状态完整还原；非法 JSON 提示无效且不改配置。
9. **外观**
   - HUD 缩放 / 透明度 / 内外圈半径 / 图标缩放 / 背景强度 / 圆环透明度与粗细 / 背景色（取色器 + 十六进制输入 + 重置）逐项生效；异常十六进制回退默认色。
10. **更新检查（独立运行形态）**
    - 设置开关生效；新版本时弹出更新对话框：正式版/预览版分组、资产列表、镜像下载开关、"下载并重启"、"忽略此版本"。
    - 断网时静默跳过，不影响游戏。
11. **移动端 / 安卓**
    - 移动端出现圆盘开关按钮（MindustryX OverlayUI 窗口或居中兜底按钮），点按开盘、点槽位选择、点盘外关闭。
    - 安卓设备安装合并 jar 能加载（验证 `classes.dex` 有效）。
12. **MindustryX 兼容**
    - 有 MindustryX 时走 `mainX` 入口正常加载；低于 `2026.04.03.B439` 的 MDtX 被明确拒绝并提示升级，而不是半兼容崩溃。

## 新增自动化测试的原则

当前仓库不接自动化。若未来要加，参照 Neon 的做法：纯函数、可离线断言的逻辑（版本比较 `compareVersions`、表达式解析器 `ConditionParser`、十六进制颜色归一化）优先做成 main() 断言式 JavaExec 回归任务并接进 `check.dependsOn`；依赖游戏运行时的行为继续走手测。
