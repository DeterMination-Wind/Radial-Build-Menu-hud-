# Radial Build Menu / 圆盘快捷建造

## 中文

> 常用建筑就在鼠标旁，建造节奏不必被菜单打断。

Radial Build Menu 是一个面向高频建造的客户端工具。按住快捷键即可在鼠标附近打开圆盘菜单，松开后直接切换到目标建筑，让你在铺线、速建和维修时少花时间翻找方块。

圆盘布局可以按自己的习惯整理，也可以针对不同星球、时间或玩法准备不同配置。它不增加新的建筑，只改变本地的建造选择方式。

### 快速开始

安装后在 设置 → 控制 中绑定圆盘热键，再到 设置 → 模组 → Radial Build Menu 配置槽位。按住热键打开菜单，移动鼠标指向目标后松开即可选择。

### 安装

将 radial-build-menu.zip 或 radial-build-menu.jar 放入 Mindustry 的 mods 目录并启用。Android 端请使用 Release 中包含 classes.dex 的 radial-build-menu-android.jar。

### 构建（开发者）

~~~powershell
.\gradlew.bat :radial-build-menu:jar
.\gradlew.bat jar
.\gradlew.bat jarAndroid
~~~

## English

> Keep common buildings near the cursor and keep the building flow moving.

Radial Build Menu is a client-side tool for frequent builders. Hold a key to open a radial menu around the cursor, move to the building you want, and release to switch immediately. It reduces menu hunting during conveyor work, rapid construction, and repairs.

Arrange the slots around your own habits or prepare different layouts for different planets and play styles. The mod adds no new buildings; it only changes how local building selection works.

### Quick start

Bind the radial-menu key under Settings → Controls, then configure its slots under Settings → Mods → Radial Build Menu. Hold the key, point at a slot, and release.

### Install

Put radial-build-menu.zip or radial-build-menu.jar in Mindustry's mods directory and enable it. On Android, use radial-build-menu-android.jar from Releases; it contains classes.dex.

### Build

~~~powershell
.\gradlew.bat :radial-build-menu:jar
.\gradlew.bat jar
.\gradlew.bat jarAndroid
~~~
